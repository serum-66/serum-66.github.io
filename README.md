# Serum 66 Game Labs Website

Astro-based marketing site for Serum 66 Game Labs.

## Local development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## GitHub Pages

The site is configured for `https://serum66.com` and includes a GitHub Actions deployment workflow. In the repository's **Settings → Pages**, select **GitHub Actions** as the source.

Configure the DNS records for `serum66.com` with your domain provider according to GitHub's custom-domain instructions.
